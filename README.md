# Seminário — Racismo Epistêmico e Computação (versão 3)

Apresentação web em tema claro, preparada para projetores, com **40 slides de exposição (10 para cada integrante) + 1 slide de referências**.

## Executar

Abra `index.html` em Chrome/Edge/Firefox. Não requer servidor, internet ou dependências. Os links de bibliografia exigem internet para abrir o conteúdo original.

## Controles

- `→` / `←`: avançar ou voltar
- `F`: tela cheia
- `O`: visão geral
- `N`: notas do apresentador (separadas do slide)
- `Home` / `End`: início / final
- Botão "Salvar PDF": abre a impressão do navegador; selecione "Salvar como PDF", papel em paisagem e gráficos de fundo habilitados.

## Publicar

Por ser um site estático, você pode subir `index.html` no GitHub Pages, Netlify ou Vercel, sem etapa de build. Para Vercel, importação do repositório com framework 'Other' e diretório raiz.

## Fontes e precisão

Os dados de Gender Shades, NIST e ProPublica são históricos, referentes às avaliações e análises citadas, não a todas as tecnologias atuais. Exemplos imaginários estão explicitados nos slides ou nas notas. A seção de referências oferece links para os documentos originais.

## Ajustes

Os textos e notas estão no elemento `script#slideData` de `index.html`, em JSON. Há também um `slides.json` separado para facilitar edições.
